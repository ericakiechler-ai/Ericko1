What you received

One file, named for your organisation — for example 845-VEC-your-company.html. That single file is the application. There is no installer, no account, no licence key to type in, and nothing to activate.

Everything is inside it: the calculation engine, the fonts, the documentation, and your signed licence. It never contacts a server, so it behaves identically on a machine that has never been online.

Installing it

1

Save the file somewhere permanent

Move it out of your Downloads folder. Downloads gets cleared, and you will lose the file at the least convenient moment. Somewhere like:

Documents\845-VEC\845-VEC-your-company.html

Keep the file name as it is. It identifies your licence, and support requests are much faster when you can quote it.

2

Open it

Double-click the file. It opens in your default browser and is immediately ready to use.

If it opens in something that is not a browser, right-click it and choose Open with, then Chrome, Edge, Firefox or Safari.

Do not open it from inside an email or a chat app Attachment previews in Outlook, Teams, Slack and similar strip out scripts for safety, and every value in this tool is calculated as the page loads. You will see the layout with an empty element list and an amber banner telling you the same thing. Save the file to disk first, then open it from there.
3

Make it one click away

Windows: right-click the file, Show more options → Send to → Desktop (create shortcut). You can then drag that shortcut onto the taskbar.

macOS: drag the file onto the right-hand side of the Dock, next to the Trash.

In Chrome or Edge you can also open the file, then use the browser menu → Cast, save and share (or More tools) → Create shortcut, and tick Open as window. That gives you a clean window with no address bar, which is the closest thing to a native app.

Checking your licence

The bar across the very top of the page tells you the state of your copy. It should look like this:

Licensed Your Company — Your Site12 seats Licence LIC-2026-XXXXXXPerpetualUpdates to 7 Sep 2027

Perpetual means your right to use this copy never expires. Updates to is your maintenance date: every build we release up to that date is yours. When it passes, the copies you already hold keep working exactly as before — the bar simply notes that maintenance has lapsed — and renewing entitles you to the builds released since.

If instead you see this, the copy you are running is not the one we issued to you:

Evaluation Not licensed for commissioning work.
An evaluation copy still calculates correctly Every number it produces is identical to a licensed copy. We do not degrade calculations — a tool whose output goes into live protection equipment must never quietly give you a different answer. What changes is provenance: test sheets exported from an evaluation copy are stamped as evaluation output, which is not something you want on a commissioning record. If you have bought a licence and see this bar, send us the file name and we will sort it out.

Entering your station

The tool opens on the Setup tab the first time you run it. This is the step that everything else depends on.

4

Replace the worked sample with your transformer

The values loaded are a demonstration, not your plant. Working left to right, enter from the nameplate, the CT/VT schedule and the relay's System Setup pages:

  • MVA ratings for each cooling stage, and which one the protection is set against
  • Winding voltages, frequency, impedance and phase rotation
  • Winding connections and the clock number — together these give any vector group
  • Tap changer range and the position you found it in
  • Neutral earthing arrangement for each winding
  • CT primaries, secondaries and connections, plus the ground CT
  • VT primary, secondary, connection and which winding it sits on
  • How your CMC 356 is actually wired — the amplifier mode
The CT and VT ratios are the whole ballgame Every injection value in every element is referred to these. A CT ratio entered from the drawing rather than from the nameplate on the actual CT is the single most common way to arrive on site with a table of confident, wrong numbers.
5

Read the configuration checks

At the bottom of the Setup tab the tool tells you what it thinks of what you entered — CT sizing against rated current, whether the differential slope covers your tap range, how much earth fault current your earthing arrangement actually allows, and whether your amplifier mode can drive the tests you are about to run.

Red items are worth resolving before you go any further. They usually mean a value has been entered against the wrong winding, or a rating has been read off the wrong cooling stage.

6

Save the station to a file

On the Setup tab, click Save station to a file. You get a small .json file named after the transformer.

Do this. Your entries otherwise live only in this browser on this machine: clearing browsing data erases them, and they do not follow you to another laptop. With a station file you can reopen the setup anywhere, hand it to a colleague on the same licence, or keep it in the job pack alongside the test records.

Proving it against your relay

Do this once per relay type and firmware revision, before you rely on a single number. It takes ten minutes and it is the difference between a tool you trust and a tool you hope about.

7

Check the derived currents against the relay's own metering

With load on the transformer, compare the rated primary and secondary currents on the Setup tab against what the relay is actually measuring. If they disagree, a ratio is wrong — and it is wrong in the tool, not in the relay.

8

Run one timing point and compare it to the relay's prediction

Pick a time-overcurrent element, take the first timing point, and compare the predicted operate time against what the relay itself says it will do.

If the first point disagrees, stop Inverse-curve constants have moved between firmware revisions on more than one product line. If the first predicted time is out, every other time in that table is wrong by the same factor. Tell us the firmware revision and we will check the constants.
9

Run the 87T through-fault point

Confirm the relay reads near-zero differential. That single test proves the vector group, both CT ratios and the relay's compensation all at once — and it is the fastest way to find out that something in the setup is wrong before it costs you an afternoon.

Using it on a job

TabWhat it is for
SetupThe station. Entered once per transformer, then saved to a file.
ElementsThe working tab. Pick an element from the left rail, enter the relay's settings in the middle, and the right-hand pane gives you the test points, the CMC channel table for the selected point, the applied phasors, and the things to check before you inject.
Vector calculatorA free-hand phasor workbench. Type in any set of voltages and currents and read back differential and restraint per phase, symmetrical components, power and apparent impedance. Useful for making sense of what the relay is telling you during a load check.
Test sheetEverything you sent over with Add these test points to sheet, as tab-separated text. Paste straight into Excel, a test record, or a Test Universe table.
MethodEvery equation the tool uses, written out so you can check the arithmetic by hand.

A normal sequence is: pick the element, type in the settings you read off the relay, click the test point you want in the Test points table, and copy the CMC 356 channels table into your test set. Then Add these test points to sheet and move to the next element.

Read the notes under each element The block headed Before you inject is not filler. It carries the channel limit checks for the point you have selected, the sign conventions that differ between manufacturers, and the cases where a single-phase injection will not behave the way you expect.

Working offline

There is nothing to do. The tool makes no network requests of any kind — not on the first run, not ever. Fonts, documentation and licence checking are all inside the file.

You can copy it to a USB stick, put it on a machine that has never touched a network, and it will behave exactly as it does at your desk.

Your licence and your team

Your licence covers the organisation and site named in the bar at the top, for up to the stated number of named users at that location. Those users may install it on the machines they work from.

  • Copy the file to as many machines as those users need.
  • Share station files freely inside the licensed site.
  • Do not pass the application file outside the licensed site. Every test sheet it exports carries your organisation's name, so a copy that leaks is traceable back to you.
  • Additional sites and additional seats are licensed separately — just ask.

Limits and responsibility

This is a calculator, not a relay. It computes proposed injection values from settings that you type in. It does not read the device, does not know its firmware or its as-built wiring, and cannot tell whether what you entered matches what is in service.

What it does not do:

  • It does not read or write relay setting files.
  • It does not model CT saturation, burden or lead resistance. The channel warnings are about your amplifier's limits, not about whether the CT circuit will behave.
  • It does not cover CT/VT supervision logic, which varies too much between firmware revisions for a generic model to be anything but misleading.
Verify before you inject Confirm the CT and VT ratios, the curve constants and at least the first timing point against the device's own prediction before you accept the rest of a table.
