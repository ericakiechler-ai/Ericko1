Before you inject

It is one runThese states only mean anything in sequence. Build each run as a single state sequence in the CMC with the breaker status contacts wired back, and let the relay drive the transitions — restarting the test set between states resets the shot counter and the result means nothing.
Breaker simulationThe relay tracks 52a/52b to know whether its close actually took. Wire the CMC binary outputs to simulate the breaker, or the scheme will declare a close failure part-way through and the later shots will never run.
Reclaim versus resetReclaim (20.0 s) is the window after a successful close during which a new fault counts as the next shot. Reset (60.0 s) is the longer idle period that returns the counter to zero. Testing one and calling it the other is the most common mistake on this element.
Instantaneous blockingShot 1 is fast, everything after it waits for the time curve. Expect the trip times to lengthen from shot 2 onward — that is the setting working, not a slow relay.

Before you inject

The middle current is the testEverything turns on one current sitting between the two thresholds: 9.000 A. It must not trip while the window is open and must trip once it closes. If it behaves the same in both states the element is doing nothing.

Method

How this tool arrives at its numbers

Everything below is stated so the arithmetic can be checked by hand. It does not replace the relay manual, the setting file or the coordination study — it replaces the conversion between them and the test set.

Reference frame

All applied quantities are secondary, at the relay terminals, and all angles are quoted against V L1 at 0° with counter-clockwise positive — the same convention as the CMC’s own phasor display.

Z secondary = Z primary · CTR / VTR = Z primary × 1.0435 Z1 total = 0.650 Ω/mi × 8.0 mi = 5.200 Ω pri = 5.426 Ω sec V L-N nominal = VT secondary / √3 = 69.28 V

Placing a fault on the line

A fault a fraction x of the way to the remote end is presented by making the relay’s own measuring loop come out at x · Z1. Which loop that is depends on the fault type, and only the ground loop carries the residual compensation:

phase loop Z = (V L2 − V L3) / (I L2 − I L3) no k0 ground loop Z = V L1 / (I L1 + k0 · 3I0) with k0 k0 = (Z0 − Z1) / (3 · Z1) = 0.7448 +5.8°

A single-phase injection makes 3I0 equal to the phase current, so the ground loop denominator becomes I · (1 + k0) and the voltage needed is the line impedance multiplied by |1 + k0| — here 1.7426. That single factor is why ground reaches can measure wrong while every phase reach measures right: it is k0 or Z0 at fault, not the reach setting.

Autoreclose — 79

Nothing in this element is a magnitude. Two runs are built and every test point is one state of one of them: a permanent fault that must spend every shot and reach lockout, and a transient fault that must reclose once and then reset. The timeline shows where the selected state sits.

Reclaim and reset are different timers and are the usual source of confusion. Reclaim is the window after a successful close during which a new fault counts as the next shot. Reset is the longer idle period that returns the shot counter to zero.

Cold load pickup

Everything turns on one current placed between the normal pickup and the lifted one. It must not trip while the window is open and must trip once the window closes. If the relay behaves the same in both states, the element is doing nothing.

Broken conductor — 46BC

Reducing one phase to a fraction f of the other two gives the sequence currents directly:

I1 = (2 + f)/3 I2 = (1 − f)/3 I2/I1 = (1 − f)/(2 + f) for a target ratio r: f = (1 − 2r) / (1 + r)

A fully open conductor is f = 0, giving a ratio of 50% — the most a single break can produce, and the ceiling for this test method.

Inverse-time curves

IEEE C37.112 t = TDM · [ A / (M^p − 1) + B ] IEC 60255 t = TDM · [ K / (M^E − 1) ] IAC / ANSI t = TDM · [ A + B/(M−C) + D/(M−C)² + E/(M−C)³ ]

Curve constants have moved between firmware revisions. Check the first timing point against the relay’s own prediction before accepting the rest.

What this tool does not do

  • Coordination. It gives the operate time at a multiple; whether that time sits under the upstream relay and over every downstream fuse and recloser is read off the coordination study.
  • 60 VT and CT supervision. The logic varies enough between firmware revisions that a generic model would mislead rather than help.
  • Non-homogeneous lines. Every impedance here assumes one uniform circuit. Real feeders change conductor, tap off and run partly underground.
  • Setting file import. Settings are entered by hand, which means they get read off the relay once and checked.

Before the first use on a job

  • Enter the real line constants and confirm the derived Z1, Z0 and k0 against the line-constants sheet and against what is actually in the relay.
  • Run one 51P timing point against the relay’s predicted operate time. If they agree, the curve constants here match your firmware.
  • Run the fault locator at 25% and 75% for both an A–G and a B–C fault. Matching phase results with drifting ground results points at k0, not at the relay.
  • Run the full permanent-fault reclose sequence with the breaker simulated. Any element that gets tested in isolation and then behaves differently inside a reclose cycle is worth finding on a bench rather than on the circuit.
