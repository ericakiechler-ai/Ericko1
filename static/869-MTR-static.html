Before you inject

What the relay measuresWith the average current at or above FLA the unbalance is I2/I1. Below FLA it is I2/FLA, so a lightly loaded motor does not trip on a ratio that carries no heat. At 1.00 ×FLA load the pickup point is in the I2/FLA regime — the phase is reduced further than the I2/I1 ratio alone would need.
Exact solveReducing one phase to a fraction f of the other two gives I1 = (2+f)/3 and I2 = (1−f)/3 of the load current, so I2/I1 = (1−f)/(2+f) and the average current equals I1. For a target unbalance r: f = (1−2r)/(1+r) when load ≥ 1+r, and f = 1 − 3r/load below that.
The thermal model sees it tooWith K = 6.0, unbalance makes the thermal model behave as though far more current were flowing. At the 15% trip point the positive-sequence current is 0.850 ×FLA but the equivalent heating current is 0.926 ×FLA — a penalty of 1.089×. How this tool arrives at its numbers

Everything below is stated so the arithmetic can be checked by hand. It does not replace the relay manual, the setting file or the motor’s thermal-limit sheet — it replaces the conversion between them and the test set.

Reference frame

All applied quantities are secondary, at the relay terminals, and all angles are quoted against V L1 at 0° with counter-clockwise positive. Currents are expressed in multiples of full load, because that is the language every motor setting is written in.

FLA secondary = FLA primary / CTR = 180.0 / 40.0 = 4.500 A locked rotor = 6.00 × FLA = 27.000 A secondary

Equivalent heating current

This is the one calculation that makes a motor relay different from every other relay in the family:

Ieq = √( I1² + K · I2² ) K = 6.0

Negative-sequence current induces double-frequency currents in the rotor, which heat it several times harder than the same magnitude of balanced current. K is the weighting, and it means a modestly unbalanced supply trips the thermal element far sooner than its measured phase current suggests. Every thermal calculation in this tool runs on Ieq, not on the applied current.

The overload curve

standard form t = CM · A / ( Iⁿ − 1 ) hot curve t hot = hot/cold ratio × t cold IEC replica t = τ · ln[ I² / (I² − (k·SF)²) ]

Published motor overload families differ between products and firmware revisions, so the constant A is exposed rather than assumed. The honest way to set it is the fit mode on the Setup tab: read one point off the relay’s own curve display — a current multiple and the time it shows — and the tool solves

A = t · ( Iⁿ − 1 ) / CM

Check a second point at a different multiple afterwards; that confirms the exponent as well as the constant. Until you do, treat every predicted time here as provisional.

Thermal capacity

accumulation d(TCU)/dt = 100% / t(Ieq) decay TCU(t) = TCU₀ · e^(−t/τ)

τ is 15 minutes running and 30 minutes stopped here. The model has memory, which is why the order of your tests changes the answers: a point run on a warm model reads short. Reset the capacity between points where the relay allows it and record the starting value for each.

Does the protection fit the machine?

A motor relay is the one place where the tool can check the settings against the machine rather than just against themselves. Three comparisons matter, and all three are made on the Setup tab:

  • Curve under the damage point. At locked rotor the cold curve gives 9.99 s against a safe stall time of 20.0 s. The curve must sit below the stall point or a locked rotor burns before the relay operates.
  • Curve above the start. The motor needs 8.00 s to accelerate. The hot curve reaches trip at 7.49 s — if that is shorter than the acceleration time, a warm restart trips before the machine finishes starting.
  • Short circuit above locked rotor. A 50P pickup at or below 6.00 ×FLA trips on every healthy start.

Any of these three failing is a setting finding, not a test failure. Raise it rather than working around it on the test set.

Unbalance

one phase at fraction f: I1 = (2 + f)/3 , I2 = (1 − f)/3 (of the load current) I2/I1 = (1 − f)/(2 + f) , I_avg = I1 relay measures: I2/I1 when I_avg ≥ FLA , I2/FLA when I_avg < FLA for a target r: f = (1 − 2r)/(1 + r) when load ≥ 1 + r f = 1 − 3r/load when load < 1 + r

The below-FLA rule is the relay’s, not this tool’s: it keeps a lightly loaded motor from tripping on a ratio that carries no heat. A fully open phase is f = 0, giving 50% when the load is at least 1.5 ×FLA and load/3 below that — the most a single break can produce. Beyond it you need a reversed phase.

What this tool does not do

  • RTD inputs. Stator and bearing temperature protection is tested with resistance boxes on the RTD inputs, not with a current source. That belongs to a different procedure.
  • 40 loss of excitation on synchronous machines. That is an offset-mho characteristic in the impedance plane; the 889 generator tool in this family does that arithmetic. The 55 power-factor element here is the coarser substitute.
  • 60 CT/VT supervision. The logic varies enough between revisions that a generic model would mislead rather than help.
  • Setting file import. Settings are entered by hand, which means they get read off the relay once and checked.

Before the first use on a job

  • Enter the real nameplate and thermal-limit data, then read the Setup tab’s checks before touching the test set. They will tell you whether the settings fit the machine.
  • Put the overload curve into fit mode from a point read off the relay, and confirm with a second point at a different multiple.
  • Plan the thermal points as one ordered run with resets between them, and write the starting thermal capacity next to every recorded time.
  • Run the start-inhibit points on 51LR, 37 and 27 — the elements that must not operate during a start are the ones that strand a motor in service.
